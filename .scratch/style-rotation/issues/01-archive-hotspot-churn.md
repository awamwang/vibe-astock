## What to build

打开短线风格页，页顶出现风格轮动摘要，能看见相对上场已定稿的风格热点进入/离开。场次定稿后，把当场短线风格指数报价落盘（涨幅、最新价、涨跌家数）；风格轮动只比较相邻已定稿场次。本场尚未定稿时，展示最近两场已定稿的进入/离开，并写清对照日期，不得把本场随盘涨幅拿去对上场定稿算轮动。没有上场存档则为不足，不跳过中间场次、不插值冒充。当场涨幅（相对昨收）不是风格轮动。不新开页面、不进短线共振、不写入 Cap。不补高低开昨收。假存档可测。

这是存档壳 + 风格热点进入/离开这一条端到端路径；位次差、Spearman、z-score、收盘新高本张不做。

派生块形状（口径，不是接口承诺）：

```
rotation:
  status: ok | partial | absent   # absent=没有两场已定稿存档可对；partial=有对照日期但热点不能比
  against: { date } | null
  hotspot_enter: [key]
  hotspot_leave: [key]
```

## Acceptance criteria

- [ ] 现有风格指数 GET 仍 200，响应带轮动派生块；不新增 HTTP 路径
- [ ] 场次定稿后，下一次成功装配的快照落盘；未定稿快照不得作为轮动的本场或上场
- [ ] 同一场次定稿可覆盖写；缺上场存档时风格轮动为不足，不拿更早场次顶上
- [ ] 摘要列出风格热点进入/离开，对照日期可见
- [ ] 本场未定稿时对照最近两场已定稿，文案写清日期，不把本场随盘当本场
- [ ] 短线共振页与定档 / Cap 不出现风格轮动
- [ ] 假存档可测，不打东财网络
