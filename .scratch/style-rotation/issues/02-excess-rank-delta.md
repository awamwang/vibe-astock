## What to build

短线风格页列表能看见相对上场已定稿的超额位次变化与涨幅差。涨幅差 = 本场涨幅 − 上场已定稿涨幅，这里的上场涨幅是昨场涨幅，不是昨收。超额位次只在风格热点候选集上排（打板风格、市值风格、短线属性、红利、金融；宽基、外围、中证全指自己不参赛），名次上升为正。两场都缺中证全指则不报超额位次；该 key 上场缺涨幅则该项涨幅差为不足。不把涨幅差叫风格轮动的全部，也不把组内领涨的位次冒充超额位次。

## Acceptance criteria

- [ ] 列表项能看见相对上场已定稿的涨幅差；文案不把它说成相对昨收
- [ ] 超额位次变化按风格热点同一套候选与超额排序；宽基、外围、中证全指不参赛
- [ ] 名次上升为正；超额并列时排序稳定（与风格热点同一套稳定键）
- [ ] 两场中任一场缺中证全指则不报超额位次；该 key 上场缺涨幅则涨幅差不足
- [ ] 本场未定稿时，位次与涨幅差仍只比较最近两场已定稿，不拿随盘当本场
- [ ] 假存档可测：并列稳定、缺基准无位次、缺上场涨幅不足
