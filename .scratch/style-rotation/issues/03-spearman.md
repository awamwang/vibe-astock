## What to build

风格轮动摘要上能看见相邻已定稿场次、同一套超额位次向量的 Spearman 相关。相关低只表示换得快，不是机会，也不写成情绪周期或题材主线轮动。重叠有效项不足则为不足。参与相关的项数必须可见。不进短线共振、不写入 Cap。

## Acceptance criteria

- [ ] 摘要展示 Spearman 相关，用的位次向量与超额位次变化同一套候选与排序
- [ ] 参与相关的重叠有效项数可见；项数不足则为不足，不拿别的组填
- [ ] 文案不把相关低写成机会、不叫情绪周期、不叫题材主线轮动
- [ ] 本场未定稿时仍只比较最近两场已定稿
- [ ] 短线共振页看不到该数
- [ ] 假存档可测：同序接近 1、完全反序为负、项数不足为不足
