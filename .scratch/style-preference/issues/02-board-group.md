# 02: 打板风格组同号

**What to build:** 摘要上能看见打板风格组相对中证全指是同向 / 反向 / 近平 / 不足。均值只含那 7 条核心；有效项少于 4 为不足；绝对值小于 0.1% 为近平。缺中证全指时不报同号，价差和组内涨幅排序仍在。

**Blocked by:** 01 页顶大小盘价差

**Status:** ready-for-agent

- [x] 打板风格组均值只含昨日涨停表现、昨日涨停、昨日连板（含一字 / 不含一字）、昨日打二板以上、昨日首板、昨日炸板
- [x] 高换手、高振幅、触板不进该组均值
- [x] 有效项少于 4 条 → 不足，不报均值也不报同号
- [x] 组均值或中证全指绝对值 < 0.1% → 近平
- [x] 否则同号为同向、异号为反向
- [x] 缺中证全指时不报同号；大小盘价差和组内涨幅排序仍可报
