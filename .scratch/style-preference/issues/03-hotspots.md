# 03: 风格热点、组内领涨与宽度标

**What to build:** 摘要列出风格热点（五组里超额前 5，再滤宽度，不补位；宽基/外围/中证全指不参赛）。各组涨幅第 1 未进热点则标组内领涨。列表上标价升面窄 / 价跌面宽。缺全指时无热点，组内领涨仍按涨幅。

**Blocked by:** 01 页顶大小盘价差

**Status:** ready-for-agent

- [x] 热点候选组：打板风格、市值风格、短线属性、红利、金融；排除宽基、外围、中证全指
- [x] 按超额降序取前 5，再过滤宽度（有家数须上涨占比 ≥ 0.5）；淘汰后不以第 6 名补位
- [x] 超额并列按项的稳定键排序
- [x] 高换手等仍可进热点候选，只是不进打板风格组均值
- [x] 各组当场涨幅第 1 且未进热点则标组内领涨（含宽基、外围）；组内领涨按涨幅不是超额
- [x] 有涨跌家数且涨幅符号与上涨占比 0.5 反侧则标价升面窄或价跌面宽
- [x] 缺中证全指时无热点，组内领涨仍按涨幅
