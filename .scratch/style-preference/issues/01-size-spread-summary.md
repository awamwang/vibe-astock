# 01: 页顶大小盘价差

**What to build:** 打开短线风格页，页顶出现风格偏好摘要，能看见默认的大小盘价差（东财小盘 − 大盘）。国证2000 − 沪深300 作为次行对照，文案写全名，不叫大小盘价差。任一侧缺报价则该差不足。同一条短线风格指数快照带上派生块；前端只渲染，不重算。假报价可测。这是摘要壳和价差这一条端到端路径；热点、同号本张不做。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 短线风格页顶有风格偏好摘要，显示大小盘价差（东财小盘 − 大盘）
- [ ] 国证2000 − 沪深300 若两侧都有报价则作为对照出现，且不叫大小盘价差
- [ ] 小盘或大盘缺报价时，大小盘价差为不足，不拿单边冒充
- [ ] 官方差任一侧缺则不展示该对照
- [ ] 现有风格指数接口仍返回同一快照，并带上派生块；不新开路径
- [ ] 假报价装配后可断言价差与对照；微盘不改写大小盘价差
- [ ] 文案不出现短线情绪、风格轮动、把昨日涨停表现叫赚钱效应
