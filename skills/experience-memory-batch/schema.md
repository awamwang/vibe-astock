# 经验记忆批量整理：字段与示例

与 `duanxian.experience.commit_files` / 前端 `OrganizeDraftFile` 对齐。

## `files[]` 项

| 字段 | 必填 | 说明 |
|------|------|------|
| title | 是 | 教训核心，无日期后缀 |
| date | 是 | `YYYY-MM-DD` |
| category | 是 | 五选一 |
| summary | 是 | ≤40 字 |
| content | 是 | 正文 Markdown，不含元数据行 |
| filename | 否 | 新主题可省略；合并已有必须原样保留 |
| stocks | 否 | `{"code": "6位或省略", "name": "名称"}` |
| sectors | 否 | `{"name": "板块/题材"}` |

提交包：

```json
{
  "files": [
    {
      "title": "热板块有冲高预期时不要在零轴卖掉",
      "date": "2026-01-29",
      "category": "踩坑",
      "summary": "板块很热仍有冲高预期，零轴卖掉属于提前离场。",
      "content": "## 标的与计划\n- …\n",
      "stocks": [{"name": "利通电子"}],
      "sectors": []
    }
  ]
}
```

## 分类

| 分类 | 何时 |
|------|------|
| 踩坑 | 做错了什么、为何亏、下次避免。`❌` 且备注指向执行/认知错误时优先 |
| 操作指引 | 某情景下怎么做（节奏、等待、高低切） |
| 方法论 | 可复用框架/原则，不绑单笔细节 |
| 盘感复盘 | 对某场/某段盘面的体感（大盘、黑天鹅、情绪博弈） |
| 仓位纪律 | 核心是仓位、止损未执行、拖几天不卖 |

卖出条件里的 `20%/-5%` 是止盈止损，不是仓位。仓位列才是仓位。

## 去重

跳过或合并，仅当已有主题同时满足：

- 日期相同
- 主标的相同（同名个股或同一大盘事件）
- 备注/计划描述同一件事

教训相似但日期或标的不同 → **仍新建**。

## 输入表示例 → 输出

输入行：

```
2026/01/29	个股	利通电子	看板块	反包涨停	大弱就走				❌	板块很热，就有冲高预期的，0轴就走了
```

输出要点：

- `date`: `2026-01-29`
- `category`: `踩坑`
- `title`: 热板块有冲高预期时不要在零轴卖掉
- 正文保留「反包涨停」「大弱就走」「零轴」

## 落盘后形态

系统会包一层：

```markdown
# {title}-{date}

- 日期：{date}
- 分类：{category}
- 摘要：{summary}
- 个股：…
- 板块：…

## 正文

{content}
```
