## AKTools（本仓库托管）

- 依赖：`requirements.txt` 中 `aktools`；`server.py` startup 自动 `ensure_started`（默认 `127.0.0.1:8988`）。
- 关闭托管：`AKTOOLS_MANAGED=0`（仍可连外部已启动实例）。
- 单独拉起：`scripts/run_aktools.cmd`。
- 状态 / 刷新：`GET|POST /api/config/market-series`（`ensure_fresh`：落后才拉；**增量**补 last→target；`force=1` 全量重拉）

## S 算法（已落地，设置页可选）

| 算法 id | 说明 |
|---|---|
| `hard_rules` | 默认。无 S，涨停生态硬规则树 |
| `qcj_degree` | 趣财经 `temperatureDegree` 原样当 S |
| `percentile_qcj_em` | 趣财经序列 + 东财补炸板/高度，分位等权合成 0–100 |
| `fusionintel` | 聚变智研宏观恐贪原样当 S；须在设置页保存 API Key |

有 S 时定档：退潮/过热叠加仍优先，其余按 S&lt;20 / 20–55 / 55–80 / &gt;80 落档。改算法后需重算预算。
