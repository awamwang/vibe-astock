## P0 · Strong

### 收拢复盘日的市场真相（定稿日档案）

**强度**：Strong · **依赖**：in-process  
**文件**：`duanxian/settled_archive.py` · `emotion_metrics.py` · `market_facts.py` · `theme_tree.py` · `data.py` · `review_store.py` · `frontend/src/lib/agent.ts` · `EmotionMetricsPanel.tsx` · `MarketFactsPanel.tsx`

**问题**：「D 日发生了什么」拆成多处 shallow module；`market_facts` 偷用 `emotion_metrics` 的 `_coverage` / `batch_pct`；题材树在 `data` 与 `review_store` 两边都能重建。

**方向**：一个 deep「定稿日档案」同时给出派生情绪指标与客观事实（含题材树）；分析师 / UI 只做投影 adapter。

**Wins**
- locality：覆盖率 / 池子只活一处
- leverage：复盘、周报、预算读同一档案
- 面板不再各自猜 dict 形状

**进度（2026-08-24）**
- [x] 新建 `duanxian/settled_archive.py`：`coverage` / `settled_pool` / `emotion_half` / `facts_half` / `archive` / `theme_tree_of`
- [x] `market_facts` 不再偷用 `emotion_metrics._coverage`；定稿池唯一入口
- [x] `data.get_*`、`trade_store.gather_readings`（指标半边）、`weekly` 定稿池改走档案
- [x] 题材树 build 只经 `settled_archive.theme_tree_of`（读时补树 / 周报现场补洞）
- [x] 涨停三池：`em._zt_pool` 改适配 `settled_archive.limit_pools`（即 `mf.pools`）；炸板/跌停失败不再拖垮涨停池
- [ ] 前端仍投影同一 dict（本轮未改 HTTP / TS 形状）

### 钩子 seam：emit 半边成真或删掉

**本轮不改**（2026-08-24）：写入半边与 emit 半边维持现状，不拆、不删、不上第二个 adapter。

**强度**：Worth exploring · **依赖**：ports & adapters  
**文件**：`duanxian/hooks.py` · `hook_schemas.py` · `plugins/vibe-ths-linker/plugin.py` · `tests/test_hooks.py`

**问题**：写入引擎（`import_*`）有真实 adapter（ths-linker）；向外推送（`emit_metrics` 等）生产零消费者，只有测试桩。one adapter = hypothetical seam。`build_metrics_payload` 再编排一遍市场 module。

**方向**：拆开「插件写入」与「引擎推送」；emit 要么上第二个真 adapter，要么删到需要再写。不要把测试双份当成第二个 adapter。
