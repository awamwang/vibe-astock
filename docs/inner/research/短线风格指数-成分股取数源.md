# 短线风格指数：成分股取数源

> 日期：2026-09-19。范围：短线风格页 `ITEMS` / `UNAVAILABLE` 能否拿到成分股名单、用哪条公开请求。目录以 `duanxian/style_indices.py` 为准。本仓库**尚未接入**成分股；风格页只拉当场涨幅。不推荐个股、不预测涨跌、不给买卖时机。方法口径见 [短线风格指数-情绪偏好轮动分析方法.md](./短线风格指数-情绪偏好轮动分析方法.md)。

## 结论摘要

- **东财板块 `BK*`：同源 `clist` 就能拿全名单。** `fs=b:BKxxxx`，走仓库已有的 `push2delay.eastmoney.com/api/qt/clist/get`（与 `fetchers._clist` 同主机）。2026-09-19 探测 33 条 BK 全部 `data.total > 0`。
- **官方 A 股指数：东财指数成分通道当前空，要换编制公司文件。** `api/qt/slist/get`（`secid=`）返回 `rc=102, data=null`；`clist fs=b:{secid}` 同样空；`clist fs=i:{secid}` 只返回指数自己（`total=1`），不是成分。中证走 OSS `cons.xls`，国证/深证走 `sample-detail/download-history`。
- **外围三条没有可用的股票成分请求。** 恒生、韩国综合核不到稳定 JSON；富时A50期指连续是期指合约，不是股票篮子。
- **同花顺专有项本来就没有公开报价**，更没有成分股。不要拿中证全指或东财热股冒充。
- 打板风格、新高等东财概念**每日重做成分**；中证/国证编制相对稳定。名单只描述当场篮子，不拿跨日点位趋势。

## 1. 三条能用的请求

请求均直连（与 `duanxian.fetchers._direct_get` 相同：`trust_env` 跟市场代理开关）。`User-Agent` 用 `fetchers.HEADERS`。东财可加 `Referer: https://quote.eastmoney.com/`。

### 1.1 东财板块成分（全部 `BK*`）

```
GET https://push2delay.eastmoney.com/api/qt/clist/get
pn=1&pz=100&po=1&np=1&fltt=2&invt=2
fid=f3
fs=b:BK1050
fields=f12,f14,f3
```

| 字段 | 含义 |
|---|---|
| `data.total` | 成分只数 |
| `data.diff[].f12` | 代码 |
| `data.diff[].f14` | 名称 |
| `data.diff[].f3` | 涨跌幅 % |

翻页与 `fetchers._clist` 相同：delay 镜像单页 `pz` 硬截 100，按累计条数停，不要用 `page*pz` 估算。`push2.eastmoney.com` 同路径也可，仓库板块资金流默认 delay。

`fs=b:BKxxxx+f:!50` 未作为必选；裸 `b:BKxxxx` 已够用。

### 1.2 中证成分文件（沪深京官方指数、中证主题）

```
GET https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/file/autofile/cons/{code}cons.xls
```

`{code}` 为六位指数代码（如 `000300`、`931186`）。成功：HTTP 200，`Content-Type: application/vnd.ms-excel`，Excel 表。失败：HTTP 404 且 body 是一张 JPEG（约 200KB）——**不要按扩展名当 xls 解析**。

权重文件（未在本次当主路径核行数，URL 形态与 AKShare `index_stock_cons_weight_csindex` 一致）：

```
GET https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/file/autofile/closeweight/{code}closeweight.xls
```

### 1.3 国证样本文件（`399xxx`）

**全量（用这条）：**

```
GET https://www.cnindex.com.cn/sample-detail/download-history?indexcode=399303
```

成功：HTTP 200，`Content-Type: application/octet-stream`，xlsx。列：`日期 / 样本代码 / 样本简称 / 所属行业 / 总市值(亿元) / 权重（%）`。

**不要用网页 JSON 当全量。** `GET https://www.cnindex.com.cn/sample-detail/detail?indexcode={code}&pageNum=1&pageSize=200` 的 `data.total` **恒为 20**，只是权重前 20，把 `pageSize` 开到 200 也不会变成 2000。

## 5. 落地时注意

1. **风格页还没接成分股。** 接的话：BK 走已有 `_clist`；`code` 六位且非 `399` 走中证 xls；`399` 开头走国证 xlsx；外围与 `UNAVAILABLE` 明示不足，不要空列表冒充。
2. **东财概念每日换篮子**（昨日涨停、新高、高振幅等）。名单只说明当场样本；跨日点位不可比。官方指数调样频率见编制方案，点位可比性强。
3. **中证全指文件约 1MB、上证约 0.5MB。** 随盘 20 秒刷新不要全量拉；适合点开再取、或定稿缓存。
4. **不要把涨跌家数 `up/down` 当成已有名单。** ulist 的 `f104/f105` 只是家数。
5. 直连方式与东财其它取数相同；不要为成分股去改进程级代理。

### 证据强度

| Claim | 强度 |
|---|---|
| 33 条 BK `clist` 有 `total` 与样本名 | 强（本机 GET） |
| 中证 `cons.xls` 200 + Excel MIME | 强（本机 GET） |
| 国证 download-history 行数 | 强（本机 xlsx） |
| 国证 JSON `total=20` 不是全量 | 强（pageSize=20 与 200 相同） |

| 恒生/KOSPI 无公开名单接口 | 中（常见入口失败；未穷尽全部镜像） |
| A50 期指无成分股 | 强（合约 vs 股票指数） |
