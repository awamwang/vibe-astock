# 短线风格指数：情绪偏好与轮动分析方法调研

> 日期：2026-09-17。范围：基于本仓库已接入的「短线风格指数」截面，调研如何用**可审计观测量**描述当场次大盘短线风格偏好、组内/组间强弱与轮动；对照交易所/中证/国证编制方案、金工风格轮动、学术动量与相对强度、以及短线看盘产品口径。不涉及个股推荐、涨跌预测或买卖时机。不把风格涨幅写成打板情绪。

## 结论摘要

- **「风格偏好 / 风格轮动」有成熟、可复用的方法族，但时间尺度与本仓库短线截面并不自动对齐**：交易所与指数公司给的是规模/价值成长**编制口径**（半年调样）；金工给的是月频/周频**相对强弱与因子打分**；学术动量是 3–12 个月截面或 1–12 个月时序；短线看盘产品把「昨日涨停 / 大小盘 / 新高」当**当场涨幅看板**。四套对象可以对照，不能互相冒充。
- **本仓库当前唯一 SoT 是当场 snapshot**：每项只有 `change_pct`、`price`、`up`/`down`，没有 K 线、高低开昨收、成交量、历史序列、昨日快照存档或分时点（`duanxian/style_indices.py`；前端 `ShortStyle.tsx` 只展示当场涨幅与涨跌家数）。**零成本能做的是截面排名、相对宽基超额、组均值、大小盘价差、宽度、打板风格组 vs 宽基是否同号**——这些回答「这一场钱在哪一类风格」，不回答「相对昨天换了谁」「创了几日新高」。
- **「与昨日对比 / 轮动 / 异动 / 突破跌破」不是同一缺口**：`change_pct` 已是相对前一交易日收盘的涨幅（页面口径），但「昨场涨幅 vs 本场涨幅」「排名跳变」要定稿快照存档；振幅与盘中位置要补东财 `f15/f16/f17/f18`（及可选 `f7`）；N 日高低突破要价格序列。不要用当场涨幅正负去冒充突破。
- **东财概念风格板块 ≠ 中证/国证风格指数**：仓库「大盘股 / 中盘股 / 小盘股 / 微盘股」是东财 BK 概念（`BK1663/1664/1643/1158`），公开页**未核到**选样白皮书；中证规模指数与国证/巨潮规模指数有编制方案 PDF。大小盘价差只能写成「东财市值风格组内差」或另接官方宽基，不能写成「中证大盘减中证小盘」。
- **「昨日涨停表现」= 东财 `BK1050`「昨日涨停_含一字」板块涨幅，不是赚钱效应**：赚钱效应是昨涨停样本本场收益中位/均（`CONTEXT.md`）。开盘啦「昨日涨停今表」更接近后者。国泰海通 2025-05 涨停择时与风格轮动有交叉（都看相对强弱），但对象是涨跌停生态，**不要重写成风格指数方法**；见 [短线情绪共振-分析方法.md](./短线情绪共振-分析方法.md)。
- **可审计的「异动 / 突破」必须先拆词**：交易所「异常波动」是**个股**相对分类指数的偏离值规则，不是板块指数口径；东财「板块异动」页是把个股盘口事件聚到板块，公式未公开；社区把板块「突然拉升」叫异动，无标准。可审计替代：滚动 z-score、宽度骤变、相对宽基超额跳变、Donchian/N 日新高（要序列）。
- **聚类强弱应停在描述层**：组内排名、组均值 vs 中证全指/上证、打板风格组与宽基是否同号。同号是**风格–指数截面一致性**，与打板情绪六层相对十日基线的「打板情绪共振」分属两处（ADR-0001）。不要合成进打板情绪，也不要用 LLM 黑盒当执行闸。
- **不要做的四件事**：把风格涨幅当打板情绪；用同花顺专有情绪/全 A/热股冒充公开源；把金工月频轮动阈值直接套到随盘 20 秒刷新；输出个股筛选或买卖时机。

## 1. 术语与边界

`CONTEXT.md` 已锁定：产品不推荐个股、不预测涨跌、不给买卖时机；场次 / 随盘 / 定稿；打板情绪 ≠ 指数红盘 ≠ 全市场涨跌 ≠ 环境条。本文对象是**短线风格指数截面上的偏好与轮动**，映射如下，不另发明同义词去替换锁定词。

| 通识说法 | 本文对应 | 不要混成 |
|---|---|---|
| 当场哪类风格更强（大小盘、打板样本、新高/超跌、红利、金融） | **风格偏好**：同一场次风格指数 `change_pct` 的截面排序与相对宽基超额 | 打板情绪；市场情绪；环境条温度 |
| 强势风格是否从上一类换成另一类 | **风格轮动**：跨场次排名/超额的变化（要存档） | 情绪周期六档；题材主线轮动（`theme_tree`） |
| 昨日涨停/连板样本今天的板块涨幅 | 东财概念 `BK1050/BK0815/…` 的指数涨幅 | **赚钱效应**（昨涨停样本收益中位/均） |
| 指数红盘、上涨家数多 | 宽基 `change_pct` 与板块 `up/down` 宽度 | 打板情绪；全市场涨跌家数（那是 `breadth.py`） |
| 打板资金群体封板/晋级/赚亏钱是否同向 | [打板情绪共振](./短线情绪共振-分析方法.md) | 本文的风格–宽基同号 |
| 冰点→高潮六档 | [短线情绪周期](./短线情绪周期-AI判定方法.md) | 风格排名第一 |

**工作定义（本文，非官方标准）**：

- **风格偏好**：在预先分组的指数/板块集合上，用同一场次可观测涨幅与宽度，回答「钱相对更偏向哪一组、组内谁领涨、相对宽基有没有超额」。
- **风格轮动**：相邻已定稿场次（或本场相对上一场定稿）之间，上述排序或超额的**位次变化**。当场 snapshot 做不了轮动，只能做偏好。
- **风格热点**：组内或全表排名靠前、且宽度不极端背离的风格标签。是盘面描述，不是荐股池。

打板情绪、环境条、连板股分属三处，见 `docs/adr/0001-board-emotion-env-lianban-split.md`。风格指数分析是第四处：**公开风格/行业/宽基报价的截面**，不要合进打板情绪模块。

### 2.3 缺口对照（按用户分析点）

| 分析点 | 现有字段能否做 | 缺什么 |
|---|---|---|
| 单指数强弱 | 能：`change_pct` 符号与幅度；有 `up/down` 时可看宽度 | 无历史分位，不能说「极端强」 |
| 聚类强弱（组内/组间） | 能：组内排序、组等权均值、组均值减宽基 | 等权 ≠ 市值加权；东财板块与中证口径不同 |
| 相对宽基超额 | 能：`item.change_pct − benchmark.change_pct`（同一场次） | 基准要预先钉死（建议中证全指，其次上证） |
| 与昨日对比 | **只能**说「相对昨收涨了多少」（已是 `change_pct`） | 「昨场涨幅 / 昨场排名」要定稿快照存档 |
| 当日变化趋势（振幅、方向） | 不能 | `f15–f18` 或分时点列 |
| 异动 | 不能做可审计定义 | 序列或滚动均值/标准差；或东财板块异动接口（公式未公开，不建议当 SoT） |
| 突破 / 跌破 | 不能 | N 日高低或均线，要 K 线或存档收盘 |

已有相关能力但**不要并进风格页当打板情绪**：

- 全市场宽度：`duanxian/breadth.py`（上证+深成 `f104/f105/f106`）。
- 指数涨 ∧ 上涨占比弱 ∧ 赚钱效应负：`trade_budget.width_divergence`——这是定档用的假强检测，输入是全市场宽度与赚钱效应，不是风格组。
- 外围日期标注：`overseas.py`（风格组已有恒生/A50，用途是对照，不是偏好判定）。

## 3. 成熟方案：方法从哪来、能迁到哪一层

### 3.1 指数公司：风格是怎么被定义的（编制，不是短线公式）

**中证规模**：2006-12-26 公告写明，中证100、中证200、中证500分别为大盘、中盘、小盘，沪深300为大中盘，中证700为中小盘，中证800为大中小盘（[深交所转发中证公告，新浪转载](http://finance.sina.com.cn/stock/y/20061226/09281121613.shtml)）。现行编制方案：

**中证价值/成长（Z 值选样）**：沪深300风格指数从沪深300中按成长三指标、价值四指标的标准化 Z 值，各取最高 100 只，另有相对成长/相对价值（[000919 方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/212_000919_Index_Methodology_cn.pdf)）。中证800价值用 D/P、B/P、CF/P、E/P 的 Z 值平均，取最高 250 只（[H30356 方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/H30356_Index_Methodology_cn.pdf)）。

**上证红利** `000015`：上证180空间内按三年平均股息率取 50 只（[上交所编制方案 PDF](https://www.sse.com.cn/market/sseindex/diclosure/c/10077875/files/bb1e253d8a6447be8bf77e98aa3dc8ba.pdf)；[2022-03-27 修订公告](https://www.sse.com.cn/market/sseindex/diclosure/c/c_20220327_5700336.shtml)）。

**对产品含义**：官方风格指数解决「风格篮子怎么构成」。短线看板若要说「小盘强于大盘」，应标明是东财 BK 差、国证2000 vs 沪深300、还是中证1000 vs 沪深300——三者样本不同。仓库目前最干净的官方大小盘对照是 **国证2000 vs 沪深300/中证全指**，而不是 `BK1643 − BK1663`。

### 3.2 券商金工：风格轮动怎么做（月频配置，不是随盘）

金工主流是**相对强弱 + 估值/拥挤/宏观打分**，输出行业或风格的超配/低配，不是冰点/高潮，也不是个股列表。与本仓库可迁移的是「相对基准的超额、四象限、拥挤度要序列」这几句，不是他们的月度推荐名单。

## 4. 方法族（按可审计定义写）

下列每族先给可计算公式，再标数据门槛。输出一律是**环境描述**（谁相对强、是否同号、位次是否变），不是买卖时机。

### 4.1 截面排名（零成本）

**定义**：在固定集合 \(S\)（全表或某一 `group`）上，按当场 `change_pct` 降序给秩 \(R_i\)。可选并列按宽度 \(u/(u+d)\) 排序，宽度与涨幅不一致时标「价升面窄 / 价跌面宽」。

**一手落点**：Jegadeesh–Titman、Levy、申万「把行业轮动因子化」都是截面排序；短线产品页本身就是按涨幅排列的板块表。

**可观测**：组内第 1 / 末位；全表前 k 名的组分布（例如前 8 名里打板风格占几席）——这就是「风格热点」的最小定义。

**不做什么**：不把第 1 名写成「主线龙头」或个股；不把秩当成金工 IC 回测结果。

### 4.2 相对宽基超额（零成本）

**定义**：\(\tilde{r}_i = r_i - r_b\)。基准 \(r_b\) 建议钉 **中证全指**（官方全市场代表，[000985 方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/20231208175438-000985_Index_Methodology_cn.pdf)）；展示层可并列上证。Gartley 的相对速度、金工风格超额，都是这个差。

**可观测**：\(\tilde{r}_i>0\) 为相对强；打板风格组均值超额；小盘/微盘相对沪深300超额。

**不做什么**：不把正超额写成「将延续」（JT/TSMOM 的窗长不是一天）；不拿同花顺全 A 当 \(r_b\)。

### 4.3 聚类对比（零成本）

**组内**：组等权均值 \(\bar{r}_g\)、组内极差、组内涨幅标准差（分歧）。项数少的组（红利 2 条、金融 3 条）极差噪声大，只展示、不合成总分。

**组间**：

| 对比 | 建议口径 | 注意 |
|---|---|---|
| 大小盘价差 | **优先** `csi2000.change_pct − hs300.change_pct` 或 `csi1000 − hs300` | 官方编制可审计 |
| 东财市值风格差 | `small − large`（BK1643−BK1663） | 选样未核到，须标「东财概念」 |
| 打板风格 vs 宽基 | `mean(board) − csi_all` 或 vs `sh`；再看符号是否同号 | **同号 ≠ 打板情绪共振** |
| 新高 vs 超跌 | `new_high − oversold` | 属性标签，不是价值因子 |
| 红利 vs 成长代理 | `div_csi − cyb` 或 vs `star50` | 不是中证800价值/成长；仓库无成长风格指数 |
| 金融内部 | 银行 vs 证券 | 券商更像风险偏好，银行更像防御——这是盘面通识，**不是**中信五风格公式 |

**组内分歧**：涨幅标准差高或 `up` 与 `change_pct` 反号（指数红、下跌家数更多）→ 标「价指数与宽度分歧」。这是板块级 AD，不是全市场 `breadth.py`。

**不做什么**：不把组均值加权进打板情绪分数；不把「打板风格与上证同号」写成共振页的一层。

### 4.4 跨日轮动（要定稿存档）

**定义（可审计）**：对每个 key 存已定稿场次的 `change_pct` 与秩。下一场计算：

1. 涨幅差 \(\Delta r = r_t - r_{t-1}\)（这里的 \(r_{t-1}\) 是**昨场涨幅**，不是昨收；与当前 `change_pct` 不是同一个量）。
2. 秩差 \(\Delta R = R_{t-1} - R_t\)（名次上升为正）。
3. 轮动速度：相邻两场组内秩的 Spearman 相关；相关低 = 换得快。Barberis–Shleifer 风格投资的可观测代理就是「相对业绩变化是否伴随着排名切换」。
4. 进入/离开前 k：集合对称差。

Moskowitz–Grinblatt 行业动量、申万行业动量因子，都是「过去窗收益排序 → 下窗」；短线版把窗缩到 1 个已定稿场次，**只描述切换，不声称可预测**。

**不做什么**：随盘中途不要用未定稿快照当 \(t-1\)（同一场次会被当成两场）；不要输出「轮入某风格故应超配」。

### 4.5 盘中趋势：振幅与方向（要报价字段或点列）

东财板块页已展示今开/最高/最低/昨收/振幅。可审计量：

| 量 | 公式（用 ulist 字段） | 在说什么 |
|---|---|---|
| 开盘缺口 | \((f17-f18)/f18\) | 隔夜偏好，不是打板开盘溢价 |
| 振幅 | \(f7\) 或 \((f15-f16)/f18\) | 当日波动宽度 |
| 盘中位置 | \((f2-f16)/(f15-f16)\) | 贴近高点还是低点 |
| 开后方向 | \(f2\) vs \(f17\) 的符号 | 高开低走 / 低开高走 |

**没有点列就没有「趋势斜率」**。随盘多次 snapshot 可以做成简易点列（L2 的盘中档），但 20 秒缓存不是分时成交。

**不做什么**：不把振幅大写成「主线爆发」（开盘啦把量能当主线发动机，仓库风格项还没有成交额）。

### 4.6 异动（必须拆开三套词）

| 词 | 口径 | 能否用在风格指数 |
|---|---|---|
| 交易所「异常波动」 | 个股相对对应指数的收盘涨跌幅偏离值，主板连续 3 日累计 ±20% 等（上交所主板异常交易实时监控细则 [上证发〔2023〕39号](http://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20250519_10779397.shtml)；交易规则偏离值公式见规则文本。科创板投教：连续 3 日偏离值累计 ±30%（[上交所投教 PDF](https://edu.sse.com.cn/tib/poster/c/10608211/files/b400cbd5799b4d069835399e82f8fbda.pdf)） | **否**：对象是股票，不是 BK/宽基 |
| 东财「板块异动」 | 产品页统计板块内个股异动次数与类型（[当日板块异动](https://quote.eastmoney.com/changes/boardlist.html)） | 公式未公开；可当外部对照，**不要当仓库 SoT** |
| 社区「指数异动」 | 「突然拉升/跳水」 | 口语。可审计替代见下 |

**可审计替代（要序列，L2）**：

- **z-score**：\(z = (r_t - \mu_{N}) / \sigma_{N}\)，\(\mu,\sigma\) 用近 N 个已定稿场次该 key 的 `change_pct`（不含本场）。中证风格选样本身就用标准化 Z 值，但那是基本面因子，不是日涨幅；统计定义相同，对象不同。
- **宽度异动**：\(u/(u+d)\) 相对自身近窗的 z 或分位。
- **超额异动**：\(\tilde{r}_i\) 的 z。

阈值若要写进产品，必须是工程约定并展示 N 与是否含本场，不能伪造成交易所规则。

**不做什么**：不把东财个股异动次数加总后叫「风格异动指数」除非写明源与公式；不拿 z>2 当买入信号。

### 4.7 突破 / 跌破（要高低价序列）

**可审计（Donchian / 海龟）**：价格超过过去 N 日最高价为向上突破，跌破过去 N 日最低价为向下。海龟 System 1 = 20 日，System 2 = 55 日，明确写「基于 Donchian 通道突破」（Curtis Faith, *Original Turtle Trading Rules*：[tradingblox 镜像 PDF](https://www.tradingblox.com/originalturtles/originalturtlerules.pdf)）。N=20 对应约四周交易日，与 Donchian 四周规则一致（二手综述甚多；**Donchian 原论文/1970 年测试报告本次未核到可链原文**，故突破定义以海龟规则文本为准）。

对风格指数：用板块/指数的**收盘价或最高价**相对过去 N 个定稿场次的最高收盘/最高价。没有 `f15` 时只能用收盘（`price` 定稿值）。

**时序动量版（非通道）**：过去 N 场累计收益符号为正视为「价格在自身动量上沿」——这是 Moskowitz et al. (2012) 的退化，不是通道突破，文案不要写成突破。

**社区口语（不可审计，产品不要用）**：「放量突破均线」「突破箱体」「指数站上五日线」——未指定均线周期、是否含今、用收盘还是盘中。

**不做什么**：当场 `change_pct>0` 不是突破；突破文案若出现，只描述「相对近 N 场高点」，并声明 N；不接买卖。

## 7. 额外值得关注的点

1. **宽度（advance–decline）**：美股 AD Line 是累计净上涨家数（StockCharts ChartSchool 公式：前值 + 上涨家数 − 下跌家数，[文档](https://chartschool.stockcharts.com/table-of-contents/market-indicators/advance-decline-line)）。本仓库板块 `up/down` 只能做**当场**净涨家数或比率；累计 AD 要存档。上交所「市场总貌 / 每日股票情况」核到的是挂牌数、市值、成交、换手（[sse.com.cn/market/view](https://www.sse.com.cn/market/view/)、[成交概况](https://www.sse.com.cn/market/stockdata/overview/day/)），**未核到**官方每日上涨/下跌家数字段——宽度继续以东财指数/板块字段为准，并与 `breadth.py` 分清样本。
2. **相对宽基超额的组内一致性**：组内多数成员超额同号，比单条第一名更稳；打板风格组尤其如此（成分每日重做，单条噪声大）。
3. **排名跳变 vs 涨幅跳变**：微盘一天 ±3% 常见，沪深300 同样幅度是另一量级；比较 \(\Delta R\) 或 z-score，避免用绝对 \(\Delta r\) 跨组比「谁异动」。
4. **组内分歧**：指数涨、下跌家数占优 = 权重或龙头带动。金融组（银行 vs 证券）尤其典型。
5. **轮动速度**：Spearman 低不是「机会」，只说明偏好不稳定；与情绪周期高潮（高度一致）可能相反——交叉时只展示，不合并打分。
6. **篮子漂移**：东财「昨日涨停」每天换成分，跨日 `price` 不可比出「指数点位趋势」时要小心；比涨幅、比超额比比点位更稳。中证/国证成分半年调，点位可比性强。
7. **价值成长缺口**：仓库红利组是官方红利指数；没有中证/国证成长指数。不要用创业板指冒充「成长风格」。若将来要四象限，应显式接 `000918/000919` 或 `399370/399371`，而不是用 BK 近似。
8. **拥挤度**：国盛三标尺的拥挤通常用成交额分位、波动或广度。风格 ulist 现在没有成交额；`fetchers` 已有板块资金流，但是环境条侧，合进风格页需另开口径，避免和主力净流入营销词绑在一起。
9. **LLM**：只许把第 0 层表读成自然语言（页面已有「问 AI」）。判定规则必须是显式秩/超额/同号，与周期调研「LLM 不适合单独执行闸」一致。
