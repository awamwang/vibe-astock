# 短线情绪共振：分析方法调研

> 日期：2026-09-15。范围：A 股超短 / 题材短线语境里「情绪共振」如何被定义、用哪些**可观测方式**判定；对照本仓库打板情绪、派生情绪指标、环境条与 Cap 定档，不涉及个股推荐、涨跌预测或买卖时机。

## 结论摘要

- **「情绪共振」不是交易所或证监会口径，也没有单一白皮书公式**：公开规则只规定涨跌幅限制与公开信息；实务上它指**同一场次内多层可观测信号同向**（涨停生态内部、题材/指数、资金、时间结构），与「情绪周期」的**跨日阶段序列**不是同一对象。
- **最硬、可审计的一层是涨停生态内部同向**：连板高度、晋级率、封板/炸板、涨停/跌停家数、赚钱/亏钱效应是否一起走强或一起走弱。这是打板情绪 + 派生情绪指标的截面一致性，不是六档周期机本身。
- **产品页能核到「共振」原文的，主要是开盘啦与趣财经，口径并不相同**：开盘啦写「板块与指数间的共振效应」「多主线共振」；趣财经写「全网人气共振 / 情绪共振」，指社区人气多源共识，**不是**涨停生态同向。选股宝公开首页、同花顺行情中心**未核到**名为「情绪共振」的指标口径。
- **券商金工几乎不把这个词当指标名**：国泰海通（2025-05-14）把涨跌停占比、打板收益等**五因子信号整合**成连续择时，输出是仓位/组合，不是「共振指数」。这是最接近的金工做法，但原文未使用「共振」。
- **学术可迁移的是 co-movement / herding / 涨跌停溢出 / 注意力，而不是「情绪共振」这个中文词**：Hamilton 给的是 regime 切换（更贴周期）；NBER w24014 等涨停文献解释的是涨停为何会吸引跟随，不是短线看板公式。
- **本仓库没有名为「共振」的指标或前端文案**；最接近的实现是定档时「多层读数同向才升/降档」、以及 `width_divergence`（指数与赚钱效应/宽度**不同向**则降档）。能支撑 A 族大部分判定，B/D 部分支撑，C/E 基本缺席。缺口是「同向检测」本身，不要补成荐股信号。

## 1. 术语：盘面通识「情绪共振」vs 本仓库锁定词

`CONTEXT.md` 已锁定：产品内部不把「市场情绪」和打板情绪混用；环境条、派生情绪指标也不是打板情绪。本文调研对象是盘面通识里的「情绪共振」，映射如下，**不另发明同义词去替换锁定词**。

| 通识说法 | 本仓库对应 | 不要混成 |
|---|---|---|
| 涨停生态内部是否同向（高度、晋级、封/炸、涨跌停家数、赚/亏钱） | **打板情绪**（当场次封板率、炸板率、晋级率、涨停/炸板/跌停家数、最高连板、连板家数）+ **派生情绪指标**（赚钱效应、分档晋级、梯队、情绪周期位置） | 市场情绪；把赚钱效应并进打板情绪 |
| 题材扩散 / 板块与指数是否同步 | 环境条里的主线题材（趣财经）；`theme_tree` 题材涨停密度与状态；`width_divergence` 指数 vs 宽度 | 打板情绪 |
| 量能、主力净流入、板块资金 | 环境条（选股宝/开盘啦/东财拼出的温度与量能） | 打板情绪 |
| 隔夜美股/港股 | `overseas` 对照，**不是**打板情绪，也不是共振判定 | 宏观恐贪直接当短线档 |

**工作定义（本文，非官方标准）**：在超短/题材短线里，「情绪共振」一般指**同一场次（或相邻时段）内，至少两类独立可观测层同向**——例如涨停生态走强的同时题材扩散、或指数红盘的同时板块涨停密度抬升。它回答的是「这几层现在是不是在说同一件事」，不是「现在处于冰点还是高潮」。

与「情绪周期」的关系见第 2 节；本文不把 FusionIntel / 百分位网一类指数级恐贪叫短线共振。

## 2. 「情绪共振」一般指什么，和「情绪周期」差在哪

### 2.1 制度背景（一手：交易所规则，不定义共振）

短线看板能数「涨停/跌停」，是因为规则把价格锁在前收盘的固定带宽内：

- 上交所《交易规则（2026 年修订）》3.3.13：股票、基金竞价交易实行价格涨跌幅限制，限制比例为 10%。原文：[sse.com.cn](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)。
- 科创板竞价涨跌幅比例为 20%；上市后前 5 个交易日不设涨跌幅。见《上海证券交易所科创板股票交易特别规定》第十八条：[PDF](https://www.sse.com.cn/lawandrules/sselawsrules/repeal/rules/c/10118601/files/f6fc4a1d4c1f469183a013c4dc36a535.pdf)。
- 创业板 2020-08-24 由 10% 调至 20%。制度变更本身是学术识别策略（见第 F 节），不是「共振」定义。

规则只创造了「涨停/跌停」这一可计数事件；**「共振」是观察者对多层事件是否同向的概括**。

### 2.2 盘面通识（非学术权威，但是一手产品/栏目文字）

超短语境里，「共振」出现时通常有三类所指，不宜揉成一个数：

1. **涨停生态内部同向**：高度、晋级、封板、赚钱效应一起强或一起弱。开盘啦「超短情绪透视」把涨停梯队、破板率、昨日涨停/连板/破板「今表」并列观察，并写明梯队有序是主升期特征、梯队断层预示走弱：[开盘啦 · 跟「情绪大师」学看盘](https://www.kaipanla.com/article/39873)。
2. **板块与指数同向**：某题材强度抬升的同时指数放量。开盘啦原文：「板块与指数间的共振效应，进一步强化了行情的整体强度与可靠性」；同文还用「多主线共振」描述全年主线并存：[开盘啦 · 如何用「开盘啦」看懂每一轮行情](https://www.kaipanla.com/article/39810)。
3. **个股带动板块（「共振板」）**：社区词表把「个股涨停同时带动板块集体上涨」叫共振板。淘股吧周末名词文（盘面通识，非厂商指标页）：[tgb.cn](https://m.tgb.cn/a/2uQ76Nh1PHG)。工程开源则把「板块共振」写成五维之一：同板块涨停数、梯队完整性、龙头效应——[limit-up-dao README](https://github.com/laozdao/limit-up-dao)（工程文档，不是论文）。

趣财经产品页另有一套「共振」：**全网人气共振**（淘股吧/同花顺/东财/雪球人气多源共识），文案含「在情绪共振中发现潜在的市场机会」：[qucj.com](https://qucj.com/)。这与第 1、2 类不是同一度量，映射到本仓库时应标成社区注意力层，不要写进打板情绪。

**未核到一手产品口径**：选股宝公开首页（[xuangubao.cn](https://xuangubao.cn/)）未出现「情绪共振」指标名；同花顺行情中心涨跌停计数页（[q.10jqka.com.cn](https://q.10jqka.com.cn/)）同样未核到该词。社区常提的「同花顺昨日涨停表现」属于指数/板块产品，官方指标说明页本次**未核到一手**。

### 2.3 和「情绪周期」：关系与区别

| | 情绪周期 | 情绪共振 |
|---|---|---|
| 时间轴 | 跨日（常 4–6 档：冰点→修复→升温→高潮→过热→退潮） | 同一场次或场内时段的**同时性** |
| 问题 | 「现在处于哪一阶段」 | 「这几层是不是同向」 |
| 典型输入 | 高度路径、炸板、晋级、赚钱效应的**序列** | 上述读数的**截面符号是否一致**，再叠加题材/指数/量能 |
| 失败形态 | 阶段贴错（把退潮说成升温） | 假强：一层亮、另一层反向（指数红、赚钱效应负） |
| 本仓库 | `classify_rule_phase` / `cycle_position` / 趣财经 `sentimentLevel` | **无独立对象**；定档文档说「优先看共振，不单看 S」指多层读数，不是一个字段 |

二者相关：高潮档往往伴随着内部共振（高度高 ∧ 赚钱效应非负）；退潮往往是内部负向共振（高度压降 ∧ 数据转差）。但**共振可以发生在任何档位**——冰点里几项一起更冷，也是同向。周期是记忆与切换；共振是当下一致性。

已有调研见 [短线情绪周期-AI判定方法.md](./短线情绪周期-AI判定方法.md)，本文不重复六档阈值。

## 3. 方法族 A：涨停生态内部共振

### 3.1 可观测方式

把「打板资金群体是否达成共识」拆成可数事件，看它们是否同号：

| 观测量 | 同向时通常意味着 | 一手落点 |
|---|---|---|
| 最高连板 / 连板家数 / 梯队是否断层 | 高度通道是否还在 | 开盘啦涨停梯队文案；本仓库 `live_emotion` / `vr.market._emotion` |
| 晋级率（昨涨停今日仍封；分档 1进2 / 2进3） | 接力是否接得住 | 开盘啦「一进二、二进三」；本仓库打板情绪晋级率 vs 派生分档晋级（口径不同，见 CONTEXT） |
| 封板率 / 炸板率、炸板家数 | 共识硬还是分歧 | 开盘啦「破板率低=做多共识强」；选股宝 API 字段 `limit_up_broken_ratio`（本仓库环境条） |
| 涨停家数 vs 跌停家数 | 宽度上的多空极端 | 交易所涨跌停事件 + 东财涨停四池；国泰海通用占比做因子 |
| 赚钱效应 / 亏钱效应（昨涨停今日收益中位、深亏占比） | 上一场共识今天有没有被兑现 | 开盘啦「昨日涨停今表」；东财「昨日涨停」板块 [BK0815](https://quote.eastmoney.com/bk/90.BK0815.html)；本仓库 `money_effect` / `loss_effect` |

判定方式在实务上几乎都是**符号一致性 / 阈值同时命中**，不是主成分黑盒：例如「高度仍在抬 ∧ 晋级未塌 ∧ 炸板未抬 ∧ 赚钱效应非负」视为正向内部共振；反向四项一起坏视为负向内部共振。开盘啦把多项并列展示，**未公开加权公式**。

### 3.2 和周期的衔接

- **内部共振是周期分档的截面证据**：本仓库高潮条件是「最高连板 ≥ 5 **且** 赚钱效应中位 ≥ 0」——这已经是两项同向，不是单看高度。退潮是「高度压降 **且** 数据转差（炸板/晋级/赚钱/深亏/跌停任一）」。
- **区别**：周期还依赖**近窗高度路径**（压降、近窗高位）和昨日档位（修复代理）；共振可以只问今天这几项是否同号。
- **已知拧巴**（`docs/仓位预算-定档规则.md`）：高度成单点否决后，赚钱效应与晋级再差也可能定不成退潮——文档原话是源文档强调「定档时优先看共振，不单看 S」，无 S 后「共振变成了串联否决」。这说明仓库内部也曾把共振理解为**多层同时成立**，而不是高度一票否决。

### 3.3 证据边界

涨停生态计数依赖制度带宽（10%/20%），跨板块混算会失真；本仓库 `MarketFactsPanel` 已提示 10cm / 20cm / 北交所 / ST 晋级生态不同。内部共振应在同一制度子集里读，否则「家数同向」是假同向。

## 4. 方法族 B：主线/板块与个股（或指数）同向

### 4.1 可观测方式

| 观测量 | 在说什么 | 一手 |
|---|---|---|
| 题材内涨停家数、首板 vs 连板、最高板 | 扩散还是「高标独活」 | `theme_tree._state_of`：扩散中 / 高标独活 / 延续 / 分歧加大 / 接力断档（源码客观标签，不含前瞻） |
| 头部题材占全市场涨停比例 | 主线是否聚焦 | `theme_tree.concentration` |
| 板块强度 + 指数分时是否同时放量 | 板块–指数共振 | 开盘啦原文（人工智能 vs 上证 10:30–10:50） |
| 龙头 vs 跟风 | 有中军/龙头还是只剩跟风 | 开盘啦「人气核心」标签（产品选股维度，公式未公开）；limit-up-dao「龙头效应」 |
| 指数红盘 vs 上涨家数/赚钱效应 | 指数与短线生态是否同步 | 本仓库 `width_divergence`：指数涨 ∧ 上涨占比 < 45% ∧ 赚钱效应中位 < 0 → 视为**背离**（反共振） |

### 4.2 产品页「共振」口径

- **开盘啦（一手）**：明确写「板块与指数间的共振效应」；判定材料是板块强度时间轴、区间净额、指数放量节点。另有「多主线共振」指多条主线同时存在，与「单主线内部扩散」不是同一句话。
- **选股宝（API 一手，营销页无共振词）**：本仓库调用 `flash-api.xuangubao.cn/api/market_indicator/line`，字段含 `market_temperature`、`limit_up_broken_ratio`、`yesterday_limit_up_avg_pcp`、`rise_count`/`fall_count`（`short_board.py`）。这是温度/炸板/昨涨停溢价/涨跌家数，**不是**「板块共振」专用指标。
- **趣财经（一手）**：「人气共振」= 多社区人气共识；情绪分由涨停数、炸板、题材热度、大单净流入等加权，公式未公开。
- **同花顺**：概念板块目录存在（[q.10jqka.com.cn/gn](https://q.10jqka.com.cn/gn/)）；名为「情绪共振」的官方口径**未核到一手**。

### 4.3 工程文档中的「板块共振」（非学术）

[limit-up-dao](https://github.com/laozdao/limit-up-dao) 把板块共振定义为：同板块涨停数、梯队完整性、龙头效应，权重 20%。这是开源归因模板，**不是**交易所或券商金工标准；可作「B 族常见观察清单」，不可当权威公式。其「次日展望 / 连板概率」超出本仓库合规边界，本文不采用。

## 5. 方法族 C：资金面共振

### 5.1 实务上常并列的资金层

| 层 | 可观测 | 与超短共振的关系 | 一手强度 |
|---|---|---|---|
| 成交额 / 量能 vs 均量 | 两市额、盘中预测量能 | 开盘啦：主线发酵「通常伴随着量能持续放大」；量能是环境条，不是打板情绪 | 产品页强 |
| 板块资金净流入 | 行业/概念净额 | 开盘啦区间净额；本仓库 `vr.market._sectors`、环境条主力净流入 | 数据强，命名「共振」弱 |
| 主力/大单 | 东财主力净流入 | 环境条已接；与涨停生态同向才被短线当作「资金跟上」 | 中（口径是厂商划分） |
| 龙虎榜 / 游资 | 席位买卖、花名风格 | 能看「哪路资金在板上」，不能单独证明全市场同向；席位标签边界见 [龙虎榜调研](./龙虎榜营业部标记与Tushare游资名录.md) | 中（上榜额可核，花名民间） |
| 两融 | 融资余额变化 | 国泰海通该篇**未**把两融当核心五因子；百分位网恐贪把两融当宏观子项。时间尺度偏日以上 | 中（宏观） |
| 北向 | 陆股通净买 | 超短看板当共振条件的**厂商/金工一手口径本次未核到** | 缺一手 |

开盘啦在指数放量节点用「实时龙虎榜 + 区间净额」定位强势股，这是**资金与板块–指数共振同时发生时的选股界面**，不是一个名叫资金共振的指数。国泰海通五因子全部来自涨跌停生态与可交易收益，**没有**北向/两融/龙虎榜项（见第 G 节）。

### 5.2 不要把「主力同向」写成跟单

龙虎榜是交易所公开信息的再传播；游资花名是商业/民间标注。资金面共振若要度量，只应停留在**净额/成交额/上榜额是否与涨停生态同号**，不进入席位跟单。

## 6. 方法族 D：时间结构共振

### 6.1 可观测方式

超短把一场拆成竞价 / 开盘 / 午盘 / 尾盘，看「空间（高度、溢价）与时间（何时封、何时炸）是否叠在同一方向」。

| 时段 | 常见观察 | 一手 |
|---|---|---|
| 集合竞价 / 早盘 | 板块内批量高开或一字；竞价净流入 | 开盘啦：竞价阶段批量涨停或高开「往往是该板块当日走强的重要信号」 |
| 开盘约 5 分钟 | 秒板家数 | 本仓库 `seal_quality.opening_seconds`（首封 ≤ 09:35） |
| 盘中放量节点 | 量能拐头是否与板块强度同步 | 开盘啦 10:30–10:50 例 |
| 尾盘 | 14:30 后才最终封住 | `seal_quality.late_seal` |
| 隔夜→今日 | 昨涨停今开溢价、打板成功率开、连板溢价 | 开盘啦「昨日涨停今表 / 昨日连板今表」；选股宝 `yesterday_limit_up_avg_pcp`；本仓库 `live_zt_effect` / `money_effect.open_success_rate` / `consec_premium` |

「昨日溢价与今日封板」是时间结构共振的核心截面：开盘溢价为正（空间）且今日晋级/封板仍在（时间延续），才是两层同向；只有高开、盘中核按钮，则是时间上的破裂。开盘啦把「昨日破板今表现」也列入超短透视：承接有力 vs 做空情绪——这是**上一场分歧在这一场是否被修复**，仍属时间叠加，不是周期分档本身。

### 6.2 缺一手的部分

把「竞价、午盘、尾盘」做成一个命名「时间共振」指数的券商/交易所口径，**未核到**。实务是分时段看板，不是单一公式。

## 7. 方法族 E：跨市场 / 外围共振

### 7.1 需要先拆开两个尺度

| 尺度 | 典型对象 | 是否被超短当作共振条件 |
|---|---|---|
| 宏观 / 隔夜风险偏好 | 美股收盘、港股、期指、商品 | 盘前对照常见；**不是**打板情绪的构成项 |
| 超短场内共振 | 涨停生态、题材、量能 | 开盘啦超短透视五维（涨跌家数、量能、涨停表现、大幅回撤、权重）**不含**美股期货 |

本仓库 `overseas.py` 明确做「隔夜外围：美股 / 港股指数 + 七姐妹」，用途是标注「哪一场的收盘」，避免过期行情冒充实时。代码与 ADR **没有**把它并进打板情绪或 Cap。

学术上的国际 co-movement（如 A–H、A 股与 G5 波动溢出）解释的是跨市场联动，时间尺度与识别策略都不是连板晋级。把期指/美股期货红盘直接叫「短线情绪共振」，会与宏观恐贪犯同一错：对象错位。

**结论**：外围在超短实务里是**环境对照**，偶尔与 A 股题材同向（例如海外 AI 映射），但开盘啦/趣财经超短模块并未把它写成共振条件。金工「情绪择时」五因子也不含外围。若出现「期指与连板高度同向」的培训口径，本次**未核到一手研报/产品公式**。

## 9. 方法族 G：券商金工有没有把多因子同向叫「共振」

### 9.1 国泰海通 2025-05-14（一手转载，含资格号）

郑雅斌 / 曹君豪 / 余浩淼，《大类资产与中观配置研究（五）——从涨停板、“打板策略”到赚钱效应引发的情绪择时指标》，2025-05-14。公开转载：[腾讯新闻《研报精选》](https://news.qq.com/rain/a/20250515A09EJF00)（文内资格号 S0880525040105 / S0880525040094 / S0880525040013；声明转载自国泰海通研究订阅号）。

原文可核对的 claim：

- 输入：**打板策略收益、跌停次日收益、涨停板占比、跌停板占比、净涨停占比** 五个因子。
- 判定：五因子信号**整合**；改进 1 加市场趋势过滤（上行/下行/震荡用不同阈值）；改进 2 因子加权。
- 输出：相对 Wind 全 A 的择时组合年化/波动/回撤——**连续仓位/多空**，不是冰点/高潮，也**没有名为「共振」的指标**。
- 因子逻辑：涨跌停数量反映情绪强弱；打板与跌停次日收益反映行为是否有效。涨停次日收益「并不具备连续性，较难作为领先指标」。

这与「多层同向」最像的一点是：**单因子不够，要把涨停侧与跌停侧、数量与可交易收益放在一起看**。差别是：金工输出是指数择时，本仓库输出是短线 Cap 天花板；且该文未处理题材扩散、竞价结构、北向。

全文 PDF 常加密，细节以转载要点为准，强度标「中–强」。后续周报（如量化择时和拥挤度预警）自称沿用该专题的涨跌停因子，本次未逐篇核「共振」用词。

### 9.2 其他金工

以「情绪共振」为报告标题或指标名的国泰海通/其他券商金工原文，本次**未核到**。国金「情绪脉冲」、百分位网恐贪属于宏观/日内综合分，已有周期调研说明不宜当短线档；它们也不叫共振。

### 10.2 缺什么（只谈度量，不谈荐股）

1. **没有「共振」对象**：没有把打板情绪 × 派生指标 × 环境条做成同号计数或同向得分；前端也不展示该词。
2. **A 族「同向」被高度串联否决**：读数已够做内部共振，硬规则路径上高度卡住时，赚钱效应/晋级无法独立把档位压下去——与源文档「优先看共振」不一致。
3. **B 族缺「板块–指数同步」旗标**：`theme_tree` 能说扩散/独活，不能说该题材强度是否与上证分时同向；开盘啦产品页有这条，仓库没有时间轴板块强度。
4. **C 族缺北向、缺「资金与涨停生态同号」**；两融只在可选 S 里。龙虎榜未提升为全市场资金共振。
5. **D 族缺竞价截面与盘中时段切分的正式对象**（有开盘 5 分钟、14:30 后封，没有 9:15–9:25 / 午盘命名层）。
6. **E 不应补成短线共振闸**：外围已按对照实现，与周期调研「宏观恐贪不宜单独当 Cap」一致。
7. **不要用共振去做个股排序**：limit-up-dao 式「板块共振打分 → 次日溢价」直接违反产品「不推荐个股、不预测涨跌」。若将来做同向检测，输出应停在**环境描述**（例如「打板情绪与赚钱效应同向/背离」「指数与宽度背离」），接 Cap 天花板而不是标的列表。

### 10.3 合规对齐

仓位预算「情绪管最多几成仓，不管买卖点」；共振若进入产品，只应约束**环境是否一致**，不生成买卖时机。`width_divergence` 已是这一方向的雏形：发现不同向就降档，而不是提示去追哪只。
