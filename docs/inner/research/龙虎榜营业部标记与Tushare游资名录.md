# 龙虎榜营业部标记与 Tushare 游资名录

> 日期：2026-09-02。范围：公开/半公开的龙虎榜营业部「游资标签」、风格特征、资金体量来源；Tushare `hm_list` / `hm_detail` / `top_*` 请求方式与本机实测权限。不涉及跟单策略或买卖点。

## 结论摘要

- **网上有成体系的席位标记**：游资别名 → 风格文案 → 关联营业部；主流落点为 Tushare 游资名录、同花顺/开盘啦标签、东财整理文、社区复盘文。
- **风格标签可用，资金体量多为坊间估计**：手法（打板/低吸/趋势/量化等）可回溯上榜行为校验；「百亿/十亿」类体量不可当权威；可核验的是单日买卖额、年成交额、上榜次数。
- **本机已有 `TUSHARE_TOKEN`，基础接口可用；游资/龙虎榜接口当前无权限**：`hm_list` 需约 5000 积分，`top_list` 需约 2000 积分。积分到位后即可程序化拉取名录做本地席位库。
- **落地建议**：Tushare `hm_list` 作底表 → 历史龙虎榜统计打板率/持仓天数/单笔金额分位数 → 自建风格与体量标签；勿把软件标签当跟单信号（存在造神与一席多资问题）。

## 1. 公开资料在标什么

| 维度 | 常见内容 | 可信度 |
|------|----------|--------|
| 标记 | 游资花名 ↔ 一串营业部全称 | 中（席位会换、一席多资） |
| 风格 | 打板 / 低吸 / 趋势 / 一字板 / 高位接力 / 量化扫货；偶见「善庄/恶庄」 | 中（需用近期上榜回溯） |
| 资金体量 | 「百亿级」「十亿级」等口头量级 | 低（传言） |
| 可核验规模 | 单笔龙虎榜买卖额、席位年成交额、上榜次数 | 高（交易所/榜单可交叉） |

常见风格三分法（复盘文共识量级）：

| 风格 | 典型特征 |
|------|----------|
| 打板型 | 涨停瞬间大单扫货，偏次日溢价 |
| 低吸型 | 回调/分歧逆势买 |
| 趋势型 | 沿均线分批，持仓偏长 |

补充标签：一字板、高位接力、量化竞价扫货、拉萨系（互联网散户/量化通道，≠单一游资大佬）。

### 2.3 使用边界

1. **一席多资**：同一营业部常混多路资金，标签会漂。
2. **席位会换**：游资换券商/换部常见，名录需更新。
3. **造神风险**：「交易软件 + 券商」贴标签带过营销争议，标签仅作辅助。
4. **非交易所官方口径**：花名与风格均为民间/商业标注。

## 3. Tushare 请求方式

### 3.1 鉴权

```python
import os
import tushare as ts

pro = ts.pro_api(os.environ["TUSHARE_TOKEN"])
# 或：ts.set_token("xxx"); pro = ts.pro_api()
```

本仓库环境：本机已配置环境变量 `TUSHARE_TOKEN`（未写入 `.env.example`）。项目代码目前**未**依赖 `tushare` 包。

### 3.2 相关接口

| 接口 | 作用 | 文档积分门槛（约） |
|------|------|-------------------|
| `hm_list` | 游资分类名录（名称、说明、关联机构） | ≥5000 |
| `hm_detail` | 游资交易明细（按交易日等） | 高（与游资权限同档） |
| `top_list` | 龙虎榜每日明细 | ≥2000 |
| `top_inst` | 龙虎榜机构/营业部明细 | 高（龙虎榜档） |
| `trade_cal` / `stock_basic` | 交易日历 / 股票列表 | 低（验 token） |

```python
df = pro.hm_list()                          # 全量名录；可选 name=
df = pro.hm_detail(trade_date="20260320")
df = pro.top_list(trade_date="20260320")
df = pro.top_inst(trade_date="20260320")
```

`hm_list` 输出字段：`name`（游资名称）、`desc`（风格说明）、`orgs`（关联营业部，常为逗号分隔多席）。单次最大约 1000 条，总量文档称未超 500。

权限说明：[积分与权限](https://tushare.pro/document/1?doc_id=108)、[积分获取办法](https://tushare.pro/document/1?doc_id=13)。

### 3.3 本机实测（2026-09-02）

| 接口 | 结果 |
|------|------|
| `trade_cal` / `stock_basic` | 成功（token 有效） |
| `top_list` / `top_inst` | 失败：无接口访问权限 |
| `hm_list` / `hm_detail` | 失败：无接口访问权限 |

报错形态：`抱歉，您没有接口(hm_list)访问权限…`（积分不足，非 token 无效）。

文档页本身带有完整示例表（章盟主、赵老哥、炒股养家、溧阳路、量化打板等），积分未到前可人工对照：https://tushare.pro/document/2?doc_id=311
