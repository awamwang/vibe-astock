# 风格偏好（第 0 层）

> 日期：2026-09-17。词汇以根目录 `CONTEXT.md` 为准。调研见 [短线风格指数-情绪偏好轮动分析方法.md](../research/短线风格指数-情绪偏好轮动分析方法.md)。不推荐个股、不预测涨跌、不给买卖时机。

## Problem Statement

短线风格页已经列出当场涨幅，但看不出这一场钱相对偏向哪一类风格：没有相对中证全指的超额、没有可审计的热点、没有打板风格组与宽基是否同号、也没有默认的大小盘价差。用户容易把当场涨幅叫成风格轮动，把昨日涨停表现叫成赚钱效应，或把风格描述并进打板情绪。

## Solution

在短线风格页上增加风格偏好：对已有短线风格指数快照做当场派生描述。页顶一条摘要（风格热点、大小盘价差、打板风格组同号或近平/不足、国证2000−沪深300 对照），原分组列表打标（热点、组内领涨、价升面窄/价跌面宽）。不新开页面，不进短线共振，不写入 Cap，不算风格轮动。

## User Stories

1. As a 复盘者, I want 打开短线风格页就看到风格热点, so that 不必自己在七张卡片里对涨幅做减法。
2. As a 复盘者, I want 热点按相对中证全指超额而不是相对昨收涨幅排序, so that 大盘红的时候不会把所有红盘风格都当成热点。
3. As a 复盘者, I want 有涨跌家数的热点必须上涨占比 ≥ 0.5, so that 指数大涨、多数成分下跌的篮子不会被叫成热点。
4. As a 复盘者, I want 没有涨跌家数的项仍可凭超额进热点, so that 中证红利这类宽基风格不会因为没有家数而永远进不了热点。
5. As a 复盘者, I want 宽基指数组与外围对照不进入风格热点, so that 上证、恒生、A50 不会占用热点名额。
6. As a 复盘者, I want 中证全指自己不参赛, so that 多数风格大跌时全指超额为 0 也不会变成热点。
7. As a 复盘者, I want 各组涨幅第 1 若未进热点则标组成内领涨, so that 仍能看见该组谁最强，又不把它叫成热点。
8. As a 复盘者, I want 组内领涨按当场涨幅而不是超额, so that 它表达的是组内谁领涨，不是谁跑赢全指。
9. As a 复盘者, I want 页顶看到大小盘价差（东财小盘 − 大盘）, so that 市值偏好和短线风格页上的市值组是同一套篮子。
10. As a 复盘者, I want 国证2000 − 沪深300 作为次行对照且不叫大小盘价差, so that 能看见可审计的官方差，又不和默认口径抢名字。
11. As a 复盘者, I want 小盘或大盘缺报价时大小盘价差显示不足, so that 不会用单边涨幅冒充价差。
12. As a 复盘者, I want 看见打板风格组相对中证全指是同向、反向、近平还是不足, so that 能判断打板样本篮子和全市场是否在说同一件事。
13. As a 复盘者, I want 打板风格组均值只含昨日涨停/连板/首板/炸板及一字、打二板变体, so that 高换手、高振幅、触板不会把「打板风格」拉偏。
14. As a 复盘者, I want 高换手等仍可出现在风格热点候选里, so that 它们只是不进组均值，不是从偏好里消失。
15. As a 复盘者, I want 组均值或中证全指绝对值 < 0.1% 时看到近平而不是同向/反向, so that 噪声不会被读成背离。
16. As a 复盘者, I want 打板风格组有效项少于 4 条时看到不足, so that 单条昨涨停表现不会冒充整组。
17. As a 复盘者, I want 中证全指缺报价时仍能看组内涨幅排序、大小盘价差、组内领涨, so that 缺基准不等于整页风格指数作废。
18. As a 复盘者, I want 缺中证全指时不显示超额、风格热点、打板风格组同号, so that 不会用上证或其他指数偷偷顶上。
19. As a 复盘者, I want 列表项在涨幅与上涨占比 0.5 反侧时标价升面窄或价跌面宽, so that 宽度分歧不必自己心算。
20. As a 复盘者, I want 口径条写明超额钉中证全指、大小盘价差是东财概念、昨日涨停表现不是赚钱效应, so that 不和打板情绪、同花顺专有指数混名。
21. As a 复盘者, I want 问 AI 的上下文带上风格热点、价差、同号, so that 模型读到的是派生后的偏好，而不是自己再发明轮动。
22. As a 复盘者, I want 随盘刷新时摘要和列表一起更新, so that 偏好和报价不是两套时间。
23. As a 复盘者, I want 在短线共振页看不到风格偏好, so that 不会把它当成打板情绪共振的一层。
24. As a 复盘者, I want 定档 / Cap 不因风格偏好改变, so that 风格描述不会抢打板情绪的解释权。
25. As a 复盘者, I want 页面文案不出现短线情绪、市场情绪、情绪共振、主线龙头, so that 用词和词表一致。
26. As a 复盘者, I want 不把当场涨幅或相对昨收差写成风格轮动, so that 没有定稿存档时不会假装做了跨场切换。
27. As a 复盘者, I want 页底未接入列表仍在, so that 同花顺情绪指数等专有项不会被中证全指或东财热股顶上。
28. As a 复盘者, I want 微盘不改写大小盘价差, so that 默认市值对照始终是小盘对大盘。
29. As a 复盘者, I want 热点最多 5 个且可能更少, so that 前 5 超额里宽度不合格的会被拿掉，而不是用第 6 名补位。
30. As a 复盘者, I want 超额并列时排序稳定, so that 刷新不会让第 5 名和第 6 名来回跳。
31. As a 测试者, I want 用假报价就能测完偏好规则, so that 不打东财网络也能锁口径。
32. As a 后续实现者, I want 第一批不做存档和高低开字段, so that 风格轮动、振幅、突破不会混进这一刀。

## Implementation Decisions

- 只增加短线风格指数快照上的派生块，不新开 HTTP 资源。装配完报价后纯函数算出风格偏好，随现有快照一起返回。前端只渲染，不重算超额、热点、同号。
- 测试缝选现有「假报价 → 装配 → 断言」这一层，在装配结果上再跑派生。不新开取数缝，不测 CSS。
- 超额：\(\tilde{r}_i = r_i - r_{\text{csi\_all}}\)。只钉中证全指；不并列相对上证。中证全指缺则派生块 `partial`：无超额、无风格热点、无打板风格组同号。
- 风格热点候选组：打板风格、市值风格、短线属性、红利、金融的全部项（含高换手、国证2000 等）。排除宽基指数组、外围对照组，以及中证全指自身。流程：候选里按超额降序取前 5 名为候选，再过滤——有涨跌家数的须 \(u/(u+d) \ge 0.5\)（\(u=d=0\) 视为无家数）；没有家数的只看超额。淘汰后不以第 6 名补位。超额相同则按项的稳定键排序。
- 组内领涨：每个分组（含宽基、外围）当场涨幅第 1 且未进入风格热点。缺涨幅的组不报领涨。
- 打板风格组核心子集：昨日涨停表现、昨日涨停、昨日连板（含一字）、昨日连板（不含一字）、昨日打二板以上、昨日首板、昨日炸板。等权均值，缺报价跳过。有效项 < 4 → 不足。与中证全指比：任一方绝对值 < 0.1 → 近平；否则同号为同向、异号为反向。
- 大小盘价差：东财小盘 − 大盘。任一侧缺则不足。对照：国证2000 − 沪深300，文案必须写全名，不得叫大小盘价差；任一侧缺则不展示该对照。
- 价升面窄 / 价跌面宽：有涨跌家数且 \(u+d>0\) 时，涨幅符号与 \(u/(u+d)\) 相对 0.5 的那一侧不一致则打标。无家数不打。
- 页顶摘要含：风格热点列表、大小盘价差、打板风格组同号状态、国证对照。原分组卡片保留。口径条补上述钉子。问 AI 上下文附带摘要字段。
- 文案禁词按 `CONTEXT.md`：短线情绪、把风格偏好当风格轮动、把昨日涨停表现当赚钱效应、把国证差当大小盘价差、把组内领涨当风格热点、把宽基或外围当风格热点。
- 不写入定档/Cap，不出现在短线共振页，不合成单一风格情绪分。短线精灵的突破/涨速是另一对象，本 spec 不改它。

派生块形状（口径，不是接口承诺）：

```
preference:
  status: ok | partial | absent   # partial = 缺中证全指；absent = 连风格指数都没有
  hotspots: [{ key, excess }]     # 0–5；status≠ok 则为 []
  group_leads: [{ group, key }]
  board_group: { n_valid, mean, vs: 同向|反向|近平|不足 }
  size_spread: { value | null, status: ok|不足 }
  size_spread_cnindex: { value | null }  # 国证2000−沪深300，对照
```

## Testing Decisions

- 只测对外行为：同一组假报价进装配再派生，断言热点集合、同号状态、价差、领涨、partial。不测缓存 TTL、不测 ulist、不测像素。
- 先验：现有风格指数装配单测已经用假报价锁目录与空值；偏好测试挂在同一装配出口后面。
- 必测：热点候选排除宽基/外围/中证全指；前 5 再过滤宽度且不补位；打板风格组不含高换手；有效项 3 条 → 不足；|均值|<0.1 或 |全指|<0.1 → 近平；缺全指 → 无热点无同号但仍有价差与组内领涨；小盘缺 → 大小盘价差不足；国证差不叫大小盘价差；超额并列排序稳定。
- API 级：现有风格指数 GET 仍 200，响应带派生块；不新增路径。
- 不测：Cap 数值不变（本 spec 不改定档模块；回归时短线共振页无风格文案即可）。

## Out of Scope

- 风格轮动、定稿快照存档、秩差、Spearman、z-score
- 补高低开昨收、振幅、盘中位置、板块 K 线、Donchian
- 相对上证超额、中证/国证成长价值指数、把东财差改成默认官方差
- 新页面、短线共振第二块、风格情绪分、接入 Cap / `width_divergence`
- 同花顺专有指数、东财板块异动接口当 SoT
- 短线精灵的涨速/突破/跌破阈值（已有对象，不在本刀改口径）
- ADR（grilling 已否决单独写 ADR-0004）

## Further Notes

- 第一批之后下一刀（存档 vs 高低开）未排期。
- 大小盘价差默认东财口径，是 grilling 相对调研推荐（官方差默认）的显式取舍；官方差只作对照。
- 边界（不进 Cap、不进打板情绪共振）写在词表 Avoid，不另开 ADR。
