# 消息来源

A 股盯盘/短线场景下的实时快讯与资讯来源说明。涵盖 **选股宝**（awam-stock 已接入）、**AkShare** 封装，及其他可替代的公开接口。

> 实测日期：2026-08-26

---

## 一、来源总览

| 来源 | 接入方式 | 形态 | 关联个股 | 关联板块 | 稳定 ID | 备注 |
|------|----------|------|----------|----------|---------|------|
| 选股宝 `pc/msgs` | HTTP JSON | 嵌套对象 | ✅ `AllStocks` | ✅ `BkjInfoArr` | ✅ `Id` | awam-stock 盘中 Worker 已用 |
| 选股宝 `todayDaPanYiDong` | HTTP JSON | 嵌套对象 | ❌ | ✅ `BkjInfo` | ✅ `Id` | 大盘板块异动 |
| AkShare 财联社 | `stock_info_global_cls` | DataFrame | ❌ | ❌ | ❌ | 内容常带「财联社X月X日电」 |
| AkShare 东财全球 | `stock_info_global_em` | DataFrame | ❌ | ❌ | ❌ | 7×24，东财 IP 风控需注意 |
| AkShare 新浪 | `stock_info_global_sina` | DataFrame | ❌ | ❌ | ❌ | 字段简单，适合作备胎 |
| AkShare 同花顺 | `stock_info_global_ths` | DataFrame | ❌ | ❌ | ❌ | 部分接口需 UA |
| AkShare 富途 | `stock_info_global_futu` | DataFrame | ❌ | ❌ | ❌ | 标题有时为空 |
| AkShare 东财个股 | `stock_news_em` | DataFrame | ✅ `关键词` | ❌ | ❌ | 按代码查，非全市场电报 |

## 二、选股宝

BaseURL：`https://api.xuangubao.cn`  
请求头参考 awam-stock `packages/shared/src/config/index.ts` 中 `headers.baoer`（`Origin` / `Referer` 等）。

代码参考：`awam-stock/packages/db/src/worker/data/baoer.ts`  
入库模型：`awam-stock/packages/model/src/models/MarketMessage.ts`、`YiDong.ts`

### 2.1 市场消息 `GET /api/pc/msgs`

**请求示例：**

```
GET https://api.xuangubao.cn/api/pc/msgs?subjids=9,10,723,35,469,821&limit=30
```

**响应顶层：**

```json
{
  "NewMsgs": [],
  "UpdatedMsgs": [],
  "DeletedMsgs": [],
  "HeadMark": "...",
  "TailMark": "...",
  "TailMsgId": "..."
}
```

入库主要使用 `NewMsgs`；`HeadMark` / `TailMark` 可用于增量同步。

**单条 `NewMsgs[i]` 字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | string | 消息 ID |
| `Title` | string | 标题（常即完整快讯正文） |
| `Summary` | string | 摘要，可为空 |
| `Content` | string | 正文，多数为空 |
| `AllStocks` | `{Name, Symbol, Market}[] \| null` | 关联个股，`Symbol` 如 `301666.SZ` |
| `Stocks` | 同上 | 子集；项目入库用 `AllStocks` |
| `BkjInfoArr` | `{Id, Name}[]` | 关联板块/题材 |
| `SubjIds` | string[] | 主题分类 ID |
| `Image` | string | 配图 URL |
| `CreatedAt` | ISO8601 | 如 `2026-08-26T12:35:16Z` |
| `CreatedAtInSec` | number | Unix 秒级时间戳 |
| `UpdatedAt` / `UpdatedAtInSec` | | 更新时间 |
| `Impact` | number | 影响方向 |
| `IsWithdrawn` | boolean | 是否撤回 |
| `FlashMessageType` | string | 快讯类型 |

**关联个股示例：**

```json
"AllStocks": [
  { "Name": "大普微", "Symbol": "301666.SZ", "Market": "mdc" }
]
```

**awam-stock 入库映射（`marketMessageMap`）：**

| 库字段 | API 字段 | 后处理 |
|--------|----------|--------|
| `id` | `Id` | |
| `title` | `Title` | |
| `summary` | `Summary` | |
| `content` | `Content` | |
| `stocks` | `AllStocks` | `Symbol` → 6 位代码 |
| `blocks` | `BkjInfoArr` | 保留 `{Id, Name}` |
| `subj_ids` | `SubjIds` | |
| `image` | `Image` | |
| `time` | `CreatedAtInSec` | |
| `date` | — | 本地交易日 |

### 2.2 大盘异动 `GET /api/messages/todayDaPanYiDong`

**请求示例：**

```
GET https://api.xuangubao.cn/api/messages/todayDaPanYiDong?headmark=0
```

**响应顶层：**

```json
{
  "Messages": [],
  "NextHeadMark": "..."
}
```

**单条 `Messages[i]` 字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | string | |
| `Title` | string | 如「农业股局部异动，海南橡胶触及涨停…」 |
| `BkYiDongType` | number | `1` 上涨异动，`-1` 下跌异动 |
| `BkjInfo` | `{Id, Name}` | 板块信息 |
| `CreatedAt` | number | Unix 秒 |
| `UpdatedAt` | number | |

**awam-stock 入库映射（`yiDongMap`）：**

| 库字段 | API 字段 |
|--------|----------|
| `id` | `Id` |
| `title` | `Title` |
| `type` | `BkYiDongType` |
| `block` | `BkjInfo` |
| `time` | `CreatedAt` |

## 三、AkShare

安装：`pip install akshare --upgrade`  
本仓库引用：`vr/astock.py` 中 `stock_news_em`（个股新闻）。

所有快讯接口统一返回 **pandas DataFrame**，列名为中文；无嵌套结构、无稳定消息 ID。

### 3.1 全球/市场快讯

| 函数 | 列名 | 数据源 | 示例特点 |
|------|------|--------|----------|
| `stock_info_global_cls(symbol="全部")` | 标题、内容、发布日期、发布时间 | 财联社 | `内容` 常带 `【标题】` 前缀 |
| `stock_info_global_em()` | 标题、摘要、发布时间、链接 | 东财 7×24 | 含原文链接 |
| `stock_info_global_sina()` | 时间、内容 | 新浪 | `内容` 可能含 `【标题】正文` |
| `stock_info_global_ths()` | 标题、内容、发布时间、链接 | 同花顺 | |
| `stock_info_global_futu()` | 标题、内容、发布时间、链接 | 富途 | `标题` 有时为空 |

## 四、结构差异与对接建议

| 维度 | 选股宝 | AkShare 快讯 |
|------|--------|--------------|
| 格式 | JSON 嵌套 | 扁平 DataFrame |
| 唯一 ID | 有 `Id` | 无（需 `hash(标题+时间)` 去重） |
| 关联个股 | `AllStocks[].Symbol` | 全球快讯无；`stock_news_em` 有 `关键词` |
| 关联板块 | `BkjInfoArr` | 无 |
| 时间 | Unix 秒 | 字符串，需解析 |
| 正文 | `Title` + `Summary` + `Content` | `标题` + `内容`/`摘要` |
| 分页/增量 | `HeadMark` / `UpdatedMsgs` | 每次全量拉最近 N 条 |
| 分类 | `SubjIds` | 无 |

### 统一消息模型（多源归一参考）

```typescript
interface UnifiedFlash {
  id?: string;           // 选股宝有；AkShare 需 hash(title+time)
  source: 'xgb' | 'cls' | 'em' | 'sina' | 'ths' | 'futu';
  title: string;
  summary?: string;
  content?: string;
  time: number;          // 统一 Unix 秒
  url?: string;
  stocks?: string[];     // 6 位代码
  blocks?: { id: string; name: string }[];
  tags?: string[];       // 选股宝 SubjIds
}
```

### 多源冗余推荐

1. **主**：选股宝 `pc/msgs`（已有结构化关联股/板块）
2. **备 1**：新浪 7×24 或华尔街见闻 lives（不同域名、风控面）
3. **备 2**：东财全球资讯（限流，勿与 push2 行情接口同 IP 狂打）
4. **可选**：财联社签名直连 / 同花顺快讯

## 五、约束与合规

- 上述接口均为站点/App **私有逆向接口**，非官方开放 API；免费、免 Key，但不保证 SLA，改版即挂。
- 「实时」多为秒～分钟级轮询，非交易所级推送。
- 东财系（push2 / datacenter / 资讯）共用风控，资讯与行情勿打爆同一 IP。
- 个人研究/自用常见；商用分发需单独评估版权与 ToS。
