# 内部共振用十日基线差，不复用周期位置

内部共振各层系数来自「当场读数 − 十日基线」再映到 [-1, 1]，默认基线是近十个不含本场的定稿场次均值，可在专用页改。缺天数不补 0、不补窗均值；该层有效对照 < 5 则该层不足。短线页只读默认分（等权 100 + 未改基线）；专用页改参数只出试算，并标注缺失。这不是 `cycle_position`：周期位置用十日窗 minmax 找谷底再计「第几天」。二者可以共用十场对照窗，但问题、公式和产品页都分开；打板情绪共振挂在「短线共振」页的一个板块下，不接六档周期机，也不写入 Cap。

**Considered Options**
- 固定锚点截面映射：与周期切断最干净；用户要求相对十日均值做差。
- 直接复用 `cycle_position` 的 minmax 分：会把共振做成周期位置的别名。
- 相对上一场的差：已否，避免走路径轴。
