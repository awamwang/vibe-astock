# 短线精灵不盯概念/行业/主题板块名单

短线精灵只盯短线盘面、短线风格已有刷新快照里**单独列出**的市场级序列（指定风格项 `change_pct`、溢价、环境条上涨数/下跌数、情绪温度/情绪分、打板情绪共振默认分）。不盯个股，不盯概念/行业/主题板块名单（人气榜、成交额榜、板块管理）。不把「短线风格指数」整组当一条监控指标；昨日涨停 BK 不再因共用行被盯。金融 BK、富时A50 等只在配置页单独成行时才盯。打板风格、市值风格、短线属性、其他各组已全部单独成行且默认监控；红利风格、宽基指数也全部单独成行但默认关闭。

**Considered Options**
- 做成同花顺式全市场个股 tick 精灵：这两页没有分时/5 分钟 K，且产品不荐股。
- 连板块人气/成交额 TOP 一起盯：会把主题板块名单卷进来，和「不涉及板块」冲突。
- 把风格指数里的 BK 也排除：短线风格页会整页退出精灵。
- 用「短线风格指数」共用行盯未单独列出的项：会把整组风格指数当成一条监控指标；已否决。
