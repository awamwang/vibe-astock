# 短线精灵不盯概念/行业/主题板块名单

短线精灵只盯短线盘面、短线风格已有刷新快照里的市场级序列（风格指数 `change_pct`、溢价、环境条上涨数/下跌数、情绪温度/情绪分、打板情绪共振默认分）。不盯个股，不盯概念/行业/主题板块名单（人气榜、成交额榜、板块管理）。短线风格指数里的昨日涨停 BK、金融 BK 仍盯：那是风格指数，不是主题板块名单。

**Considered Options**
- 做成同花顺式全市场个股 tick 精灵：这两页没有分时/5 分钟 K，且产品不荐股。
- 连板块人气/成交额 TOP 一起盯：会把主题板块名单卷进来，和「不涉及板块」冲突。
- 把风格指数里的 BK 也排除：短线风格页会整页退出精灵。
